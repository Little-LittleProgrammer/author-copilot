# 当前路线图

更新：2026-11-17。这里记录产品实际范围；早期 MVP 计划中的周期和未开始状态不代表当前进度。

## 目标

围绕“灵感 → 规划 → 正文 → AI 修改 → 版本审阅 → 交稿”建立本地优先的创作工作区。作者保留创作控制权，AI 修改可审阅、可恢复。

## 已交付

| 阶段 | 当前能力 |
| --- | --- |
| 工程基础 | Electron 安全壳、主进程/预加载/渲染进程边界、共享契约、CI 和打包矩阵 |
| 本地写作 | 小说与剧本、作品标签、Markdown/TXT/Word 导入、自动拆章、自动保存、草稿恢复、编辑保存与冲突保护 |
| 目录与交稿 | 新增卷/章/场景、重命名和删除、同级排序、TXT/Markdown/DOCX 导出、含 Git 历史和草稿的作品备份与独立恢复 |
| 版本与恢复 | 内置 Git、本地版本和分支、diff、Agent 快照保留与恢复 |
| 知识与 AI | SQLite FTS5 索引、增量更新、来源引用、Ask/Agent、持久对话历史；账号全局只读助手、跨作品查询、全局/本书 Skill 与原生文件工具 |
| 创作资料 | 大纲/灵感/随记管理、章节摘要、可修订事实库及来源状态、引用快照、AI 生成、编辑预览、差异审阅和确认保存 |
| 写作习惯 | 今日人工净增、速率、七日趋势、每日目标 |
| 连接与平台 | Anthropic BYOK、自定义兼容供应商、账号、托管中转、余额与用量计费 |

能力边界：章节摘要与事实库均从单篇已保存正文提炼，作者审阅后保存；事实逐条确认，尚无实体关系或全书自动事实维护。章节摘要是作者确认的单篇正文快照，来源状态在选择、窗口聚焦或手动检查时刷新，不提供全书自动提炼；知识检索尚非长期记忆；剧本使用幕/场结构，尚非专业剧本排版；Agent 审核是整轮保留/撤销；在线充值尚未开放。作品备份通过作家中心恢复为独立作品；未决 AI 任务须先处理，备份不含账号凭据、聊天和 AI 运行时快照。

## 后续顺序

[两级 AI 工作区与 Skill 首版](reports/2026-11-09-ai-workspaces-and-skills.md)已实现：首页账号全局助手只读查询及跨作品比较、作品助手、本书共享创作资产、原生工具及写前/写后 Hook。全局专用与本书 Skill 分场景加载，本书同名覆盖已通过真实 SDK 验证。Shell、外部 MCP、可执行 Skill Hook 与全局跨作品写入保持关闭。

[P0.1 创作安全](reports/2026-11-16-p0.1-delivery.md)已实现正文自动保存、主进程草稿恢复、带校验的作品备份及独立恢复、AI 断流保护、首次使用引导和发布材料工具。以下发布验收仍以实际证据为准。

1. **发布收口（M8）**：最新版本真实模型与网络故障验证、四架构 Agent/恢复完整流程、签名公证、SBOM 和开源许可材料。已有早期 Git/索引四架构证据不能替代最新版本验收。
2. **长篇知识基础**：单篇章节摘要、来源检查及[可修订事实库首版](specs/fact-library.md)已交付；下一步扩展人物与世界观实体及事实关联。评估语义检索收益，保留可定位来源。
3. **一致性与效率**：时间线、伏笔与设定冲突检查；逐修改块接受；跨卷移动、拆合章；风格预设。
4. **商业化专项**：支付订单与验签回调、幂等入账、待核对账单与运营工具。若近期目标转为收费上线，单独提升此项优先级。
5. **长期扩展**：云同步、协作、PDF/EPUB 与专业剧本格式。宠物陪伴、广告和漫剧接入保留为探索方向。

各项新增能力需要独立需求与验收，不将通用 AI 对话能力等同于已交付的结构化产品功能。
