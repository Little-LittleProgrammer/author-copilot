# 七日写作趋势

编辑器底部点击「七日趋势」，查看当前作品最近七个本地自然日（含今天）的每日净增和七日合计。统计沿用今日净增口径，包含未保存草稿，删除／撤销可产生负数。正负柱状图共用零基线，并始终显示每日数值，今天单独标记。

## 行为与数据

- 数据跨章节汇总、按作品隔离，复用本地已有的每日统计文件。没有文件的日期显示 0；功能启用前的写作活动不会补算。
- 打开、刷新、窗口重新获得焦点或本地日期切换时，先同步当前会话待保存的活动，再读取七日记录。弹窗关闭后，下次打开重新读取。
- 任一天文件损坏、读取失败或待保存的活动未同步成功时，显示重试提示，不展示部分合计，不将读取失败替换为 0，也不覆盖损坏文件。
- 加载、失败和正常展示保留相同最小内容高度。支持 Esc 关闭、键盘焦点返回入口、窄窗口及中英文界面。
- 不新增统计存储、不写入作品 Git、不上传正文或统计。不提供自选日期范围或写作目标。

## 实现边界

新增 `writing-statistics:history` 类型化 IPC，参数仅为作品 ID 和结束日期。Main 校验来源、主框架、参数及作品标签归属，每次最多读取七个日期文件，并通过原有串行队列保证读取发生在先前已接收的写入之后。日期标签采用 UTC 日历运算，避免本地夏令时切换造成缺日；结束日期由 Renderer 按本地日历提供。

- Desktop 统计与 IPC 单元测试覆盖七日补零、负数与合计、排队写入、进程重新创建、跨月／闰年／跨年、夏令时边界日期、作品隔离、损坏文件保护及非法 IPC。
- Contracts 测试覆盖新通道白名单、严格请求参数与响应边界。
- Electron 流程覆盖空记录、历史数据、未保存编辑入账、读取失败与修复重试、页面重新加载、跨日刷新、Esc 焦点返回和 880px 窄窗口；同时回归原写作统计／IME／重启流程。
