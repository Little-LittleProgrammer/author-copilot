# 参考界面布局调整

## 范围

参考本地 AuthorWrite 构建产物及作家中心、写作页截图，重新组织 Author Copilot 已有功能的位置。本轮不增加投稿、社区、奖励、新建章节等业务能力。

- 作家中心：180px 导航栏、顶部作品概览、四个快捷入口、作品筛选及书架。新建入口提供小说和剧本选择，导入、AI 设置和外观设置接入原有操作。
- 写作页：通栏工具条，下方依次为章节目录、连续正文画布、可关闭的助手面板和竖向工具栏。章节标题放入正文区，保存及版本操作留在顶部，字数和写作统计留在底部。
- 目录可搜索和隐藏；搜索命中时展示祖先路径。助手切换保持组件挂载，保留正文与尚未发送的对话输入。
- 外观设置可在写作页直接打开；自定义背景覆盖整个写作分栏区域。

## 实现边界

变更位于 Renderer。`ProjectEditorTab` 将目录作为内容传给 `EditorWorkspace`，再由 `WritingEditor` 统一布局工具条和正文分栏。编辑页的主题状态由 `EditorWorkspace` 管理。未增加或修改本轮所需的 IPC、存储或 AI 执行契约。

## 验证

- Desktop 构建及 TypeScript 检查通过。
- ESLint 无 error；保留 4 条已有 React Fast Refresh warning。
- 5 项相关 Playwright E2E 通过：目录与作品重命名、主题与背景图持久化、七日写作历史、写作工具条与助手、新布局与草稿保留。
- 新布局用例覆盖目录折叠后搜索、目录隐藏与恢复、助手模式切换、编辑页主题设置及 880×600 分栏边界。
- 独立 Electron 临时用户目录验证：作品创建、搜索、亮暗主题、中英文界面及 1600×950 / 880×600 布局；未发现 Renderer pageerror。
