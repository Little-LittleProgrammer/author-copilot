# 未来功能

两级工作区与 Skill 首版已实现，设计见[账号全局工作区、作品工作区与 Skill](ai-workspaces-and-skills.md)：首页全局助手支持账号内的作品查询与跨作品分析，作品助手聚焦本书；全局与作品 Skill 分场景加载，大纲读取、资产维护及写作技巧以技能组织。首版全局助手只读，原生改稿保留审阅与恢复；Shell 与全局跨作品写入未开放，见[交付记录](../reports/2026-11-09-ai-workspaces-and-skills.md)。

1. 宠物功能 - 作者根据自己作品里的角色生成类似 codex 的宠物，会主动关怀(长时间卡文、每日写作数据等等)
2. AI 大纲、灵感、随记等等功能（创作资料管理、AI 上下文引用、AI 生成与确认保存已实现；后续按作品内资产及 Skill 组织读取、生成、维护与写作技巧，扩展结构化设定与大纲同步）
3. 积分、充值、广告 sdk 接入
4. 码字速率、每日码字字数和写作目标（基础版本已实现，后续可扩展提醒与周期目标）
5. 自定义 AI API Key 接入（Anthropic 兼容供应商已实现；其他协议待扩展）
6. 接入漫剧生成平台

实施状态与后续顺序以 [当前路线图](../roadmap.md) 为准。
