# author-copilot

面向作者的 AI 创作副驾，帮助你记录灵感、构建故事世界、规划章节、撰写稿件并润色文本。

## 项目简介

author-copilot 是一个面向作者、小说家、编剧和长篇内容创作者的 AI 超级工作站。它将灵感捕捉、故事规划、正文写作、修改润色和创作知识管理整合到同一个工作空间中，帮助作者把零散的想法逐步转化为结构清晰、可持续推进的作品。

无论你是在构思一部长篇小说、规划连载故事、设计人物成长线，还是打磨最终稿件，author-copilot 都旨在支持完整的创作流程。

## 项目愿景

写作不仅仅是生成文字。对于严肃创作和长篇写作来说，作者更需要的是一套能够管理灵感、人物、世界观、剧情结构、章节进度、版本修改和风格一致性的系统。

author-copilot 希望成为作者的创作操作系统：
- 在灵感消失之前快速记录下来
- 用结构化空间整理故事知识和创作资料
- 在 AI 辅助下构建人物、设定和剧情线
- 规划章节与长篇叙事结构
- 在保有创作主导权的前提下提升写作效率
- 基于上下文完成修改、润色和打磨

## 当前功能

- 小说与剧本项目、多个作品标签、章节和场景管理
- Markdown 文件夹及 TXT、DOC、DOCX 导入，可预览并自动拆章
- 本地正文编辑、原子保存、冲突保护、撤销重做和查找替换
- 今日净增、码字速率、七日趋势及每日写作目标
- 大纲、灵感、随记管理；AI 生成、编辑预览、差异审阅和确认保存
- 基于选定资料、章节及作品知识检索的 Ask / Agent 对话
- Agent 文件修改审阅、整轮保留或撤销、崩溃后恢复
- 内置 Git、版本历史、差异查看及本地分支切换
- Anthropic 自带密钥、自定义兼容供应商及平台中转
- 平台账号、余额和用量记录；在线支付尚未开放
- 整部或当前章节导出 TXT、Markdown、Word（DOCX）
- 中英文、浅色与深色主题、自定义配色和背景

人物关系、世界观、时间线和风格管理属于后续愿景，尚不是完整产品功能。

## 目标用户

author-copilot 面向以下用户：
- 小说作者
- 网文作者
- 编剧
- 故事创作者
- 写作团队
- 长篇内容创作者

## 使用场景

- 将一个模糊的灵感发展为完整的故事概念
- 为长篇项目建立并维护故事设定手册
- 设计人物、动机与角色关系
- 规划多章节小说或连载项目
- 借助 AI 辅助完成场景与章节初稿
- 从清晰度、节奏、语气和风格等角度修改稿件
- 从最初灵感到最终成稿，持续管理整个写作项目

## 产品原则

- AI 应该辅助作者，而不是替代作者
- 长篇写作需要结构、记忆和上下文连续性
- 创作流程应该灵活，而不是僵硬
- 作者必须保有对声音、风格和方向的控制权
- 好工具应该降低创作阻力，而不是削弱原创性
